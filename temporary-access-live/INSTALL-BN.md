# Temporary Access Live Control — বাংলা ইনস্টলেশন

1. WordPress admin → Plugins → Add New → Upload Plugin থেকে ZIP আপলোড করুন।
2. Activate করুন।
3. Temporary Access মেনু থেকে scoped, time-limited access তৈরি করুন।

Requirements: WordPress 6.5+, PHP 8.0+, HTTPS recommended/required by the plugin security policy.
