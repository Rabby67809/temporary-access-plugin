Give scoped, time-limited content access with live monitoring, granular permissions, approvals, rollback, notifications, and session reports.

= Description =
Temporary Access Live Control creates one-time, time-limited WordPress workspaces for selected Posts, Pages, WooCommerce Products, and Elementor templates when those post types exist.

= Installation =
Upload the plugin ZIP, activate it, and open Temporary Access in wp-admin.

= Security =
Access is scoped to assigned content. The plugin does not record screen, camera, keystrokes, other browser tabs, apps, or unrestricted wp-admin activity.
